# Core Libraries

Follow the rules defined in [.claude/rules-snippets/core-libraries.md](../rules-snippets/core-libraries.md).

Key points:
- Use {{UTILITY_LIBRARY}} for common utilities.
- Use {{STATE_MANAGEMENT}} for state management and {{STYLING}} for styling.
- Use {{UI_LIBRARY}} for UI components; check existing components before creating new ones.
